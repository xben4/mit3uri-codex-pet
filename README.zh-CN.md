## 安装

### 让 Codex 帮你安装

把你想安装的版本对应的提示发给 Codex。

**原版**

> 请从 https://github.com/xben4/mit3uri-codex-pet 安装三理Mit3uri 原版。把仓库里的 `mit3uri` 文件夹复制到我的 Codex `pets` 目录，并告诉我如何选用它。

**小猪思考版**

> 请从 https://github.com/xben4/mit3uri-codex-pet 安装三理Mit3uri 小猪思考版。把仓库里的 `mit3uri-pig-thinking` 文件夹复制到我的 Codex `pets` 目录，并告诉我如何选用它。

### 手动安装

1. 解压发布 ZIP，或从本仓库下载所选版本的文件夹。
2. 将整个文件夹复制到 Codex 的 `pets` 目录。每个宠物文件夹里都有 `pet.json` 和 `spritesheet.webp`。

   | 平台 | Codex 宠物目录 |
   | --- | --- |
   | Windows | `%USERPROFILE%\.codex\pets\` |
   | macOS / Linux | `~/.codex/pets/` |
   | 自定义 Codex 主目录 | `<CODEX_HOME>/pets/` |

3. 在桌面应用中打开 **设置 → 宠物**，点击 **刷新**，然后按名称选择版本。在 Codex 命令行中使用 `/pets`。[OpenAI 宠物指南](https://learn.chatgpt.com/docs/pets)
