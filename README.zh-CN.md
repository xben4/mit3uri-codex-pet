# 三理Mit3uri · Codex 宠物

[English](README.md)

这是以三理Mit3uri 为原型制作的非官方 Q 版 Codex 宠物，仅供非商业用途。角色参考见[三理Mit3uri 的哔哩哔哩主页](https://space.bilibili.com/2030198123)。
关注紫色小猪谢谢瞄！

## 安装

### 让 Codex 帮你安装

把下方提示中的占位文字换成本发布仓库的 GitHub 链接，再发给 Codex。

> 请从 `<GitHub 仓库链接>` 安装三理Mit3uri Codex 宠物。把仓库里的 `mit3uri` 文件夹复制到我的 Codex `pets` 目录，并告诉我如何选用它。

### 手动安装

1. 解压发布 ZIP，或从本仓库下载 `mit3uri` 文件夹。
2. 将整个 `mit3uri` 文件夹复制到 Codex 的 `pets` 目录。复制后，两个文件应直接位于 `mit3uri` 文件夹内。

   | 平台 | 安装后的文件夹 |
   | --- | --- |
   | Windows | `%USERPROFILE%\.codex\pets\mit3uri\` |
   | macOS / Linux | `~/.codex/pets/mit3uri/` |
   | 自定义 Codex 主目录 | `<CODEX_HOME>/pets/mit3uri/` |

3. 在桌面应用中打开 **设置 → 宠物**，点击 **刷新**，然后选择 **三理Mit3uri**。在 Codex 命令行中使用 `/pets`。[OpenAI 宠物指南](https://learn.chatgpt.com/docs/pets)

安装所需的文件是 [`pet.json`](mit3uri/pet.json) 和 [`spritesheet.webp`](mit3uri/spritesheet.webp)。
