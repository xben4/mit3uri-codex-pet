An unofficial fan-made chibi companion for Codex, for non-commercial use only. Character reference: [三理Mit3uri on Bilibili](https://space.bilibili.com/2030198123).

| Version | Name in Codex | Install folder |
| --- | --- | --- |
| Original | 三理Mit3uri | [`mit3uri`](mit3uri/) |

## Install

### Ask Codex to install it

Paste the prompt for your chosen version into Codex.

**Original**

> Install the original 三理Mit3uri pet from https://github.com/xben4/mit3uri-codex-pet. Copy the `mit3uri` folder into my Codex `pets` directory and tell me how to select it.

**Piggy Thinking**

> Install the Piggy Thinking pet from https://github.com/xben4/mit3uri-codex-pet. Copy the `mit3uri-pig-thinking` folder into my Codex `pets` directory and tell me how to select it.

### Install manually

1. Extract the release ZIP or download the folder for your chosen version.
2. Copy the entire folder into your Codex `pets` directory. Each pet folder contains `pet.json` and `spritesheet.webp`.

   | Platform | Codex pets directory |
   | --- | --- |
   | Windows | `%USERPROFILE%\.codex\pets\` |
   | macOS / Linux | `~/.codex/pets/` |
   | Custom Codex home | `<CODEX_HOME>/pets/` |

3. In the desktop app, open **Settings → Pets**, click **Refresh**, and select the version by name. In the Codex CLI, use `/pets`. [OpenAI Pets guide](https://learn.chatgpt.com/docs/pets)
