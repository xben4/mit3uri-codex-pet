# 三理Mit3uri · Codex pet

An unofficial fan-made chibi companion for Codex, for non-commercial use only. Character reference: [三理Mit3uri on Bilibili](https://space.bilibili.com/2030198123).

## Install

1. Extract the release ZIP or download the `mit3uri` folder from this repository.
2. Copy the whole `mit3uri` folder into your Codex `pets` directory. The two files should sit directly inside the copied folder.

   | Platform | Installed folder |
   | --- | --- |
   | Windows | `%USERPROFILE%\.codex\pets\mit3uri\` |
   | macOS / Linux | `~/.codex/pets/mit3uri/` |
   | Custom Codex home | `<CODEX_HOME>/pets/mit3uri/` |

3. In the desktop app, open **Settings → Pets**, click **Refresh**, and select **三理Mit3uri**. In the Codex CLI, use `/pets`. [OpenAI Pets guide](https://learn.chatgpt.com/docs/pets)

The installable files are [`pet.json`](mit3uri/pet.json) and [`spritesheet.webp`](mit3uri/spritesheet.webp).
